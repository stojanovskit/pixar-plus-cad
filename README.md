# Pixar Plus Print & Copy Studio — CAD

**[Отвори ја апликацијата](https://stojanovskit.github.io/pixar-plus-cad/)**

Брендирана веб CAD апликација со оригиналното лого, мобилни алатки, DXF/DWG, леери, Move/Rotate и PDF/SVG Plot.

При увоз на DXF/DWG, 2D MULTILEADER ознаките со текст се задржуваат како групирани линии, стандардни стрелки и текст. Може да се поместуваат, зачуваат во проект и плотираат. Забелешките при увоз јасно означуваат што е приспособено или недостасува: блоковски ознаки, сопствени стрелки, шрафури, SHX фонтови и други неподдржани објекти. Тоа не значи дека фајлот не се отворил.

## Поставување сопствена копија на GitHub Pages

1. Создај нов Public репозиториум `pixar-plus-cad` во твојата GitHub сметка.
2. Качи ја целата содржина на папката `pixar-plus-cad/` од овој ZIP во коренот на репозиториумот. Качи ги и `.github/workflows/pages.yml` и `.nojekyll`. Не го качувај ZIP-от како единствен фајл.
3. Во Settings → Pages → Build and deployment → Source избери GitHub Actions.
4. Во Actions отвори Publish Pixar Plus CAD → Run workflow, избери main или master и почекај успешно завршување.
5. Вистинскиот линк ќе се појави во Settings → Pages и во резултатот од workflow-от.

## Твој хостинг

Качи ја содржината на `pixar-plus-cad/` во празна папка, на пример `public_html/cad/`, и отвори ја адресата со завршна коса црта. `index.html`, `assets/`, `wasm/`, `fonts/` и `pixar-plus-logo.jpg` треба да бидат во истата папка. На серверот не е потребен Node.js или PHP.

Апликацијата работи и во коренот на доменот и во потпапка. Користи веб-сервер; не отворај го index.html преку file://. `.htaccess` е за Apache и ги поставува MIME типовите; GitHub Pages го игнорира.

## Изворен код и измени

`pixar-plus-cad-source.zip` содржи комплетен изворен код, зависности, мобилни алатки, оригинално лого, GPL лиценци и workflow за градење. За нов build на компјутер со Node.js 24 и pnpm 11.25:

```bash
pnpm install --frozen-lockfile
pnpm build
```

Изградената верзија е во `site/`. За оваа готова верзија на GitHub Pages, качи ја новата содржина на site/ и задржи го готовиот workflow.

Цртежите се обработуваат локално во прелистувачот. Зачувај DXF или .nookcad проект пред затворање. Форматот .nookcad останува компатибилен со претходните проекти.

111 постојни 2D команди и опции; нема 3D, LISP или DWG извоз. Кодот и LibreDWG се GPL-3.0; задржи ги лиценците и достапниот изворен код.
